CHARACTER ART STUDIO — 사용 및 배포 안내

1. ZIP 압축을 풀면 index.html, style.css, script.js, assets 폴더가 나옵니다.
2. index.html을 더블 클릭하면 브라우저에서 사이트를 미리 볼 수 있습니다.
3. GitHub에 로그인하고 New repository를 눌러 저장소를 만듭니다(예: character-art-studio).
4. Add file > Upload files에서 ZIP 파일이 아닌 압축 해제한 파일과 assets 폴더를 업로드합니다.
   중요: index.html은 저장소 최상위(root)에 있어야 합니다.
5. Commit changes를 눌러 업로드를 완료합니다.
6. 저장소 Settings > Pages > Build and deployment에서 Deploy from a branch를 선택합니다.
7. Branch: main, Folder: /(root)를 선택하고 Save를 누릅니다.
8. 잠시 후 https://사용자이름.github.io/character-art-studio/ 에서 확인합니다.
   (저장소 이름에 따라 마지막 경로가 달라집니다.)
9. 메인 화면의 VIEW MY WORKS를 눌러 스크롤되는지, 우측 아래 홈 버튼이 나타나고 작동하는지 확인하세요.

참고: 제공된 화면을 가장 충실하게 유지하기 위해 각 Figma 화면을 이미지로 표시했습니다.
따라서 본문 글씨와 그래픽을 개별적으로 편집하거나 캐릭터/마법진을 따로 움직이려면
추후 Figma 원본 레이어 또는 투명 PNG/SVG 리소스를 사용해 재구성해야 합니다.
